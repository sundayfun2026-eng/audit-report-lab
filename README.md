# AI 辅助模块说明

> 05-ai / 工具层 · AI 审计报告 Prompt Library

## 定位

本目录收录可直接复制使用的 AI 提示词(Prompt),用于辅助审计人员在"全过程成稿"机制下更高效地完成报告各环节工作。所有 Prompt 均围绕本项目的方法论体系(FDRRRA 六要素、五层原因模型、标题四要素等)设计,而非通用写作提示词。

## 使用原则

1. **AI 辅助生成,人工必须复核**——AI 生成的问题标题、原因分析、报告草稿均为初稿建议,最终判断和事实核实责任在审计人员本人
2. **不得输入涉密或未脱敏信息**——使用外部 AI 工具前,请确认输入内容已按机构保密要求处理
3. **Prompt 是起点,不是终点**——根据实际项目情况调整 Prompt 中的角色设定、要求细则

## 收录 Prompt

| 文件 | 用途 |
|---|---|
| `审计问题提炼Prompt.md` | 基于审计事实批量生成候选问题标题 |
| `审计报告生成Prompt.md` | 基于六要素结构化信息生成发现条目初稿 |
| `审计报告质量复核Prompt.md` | 对照十条黄金法则对报告草稿进行自动化初筛 |

## 与"审计开始即报告开始"理念的关系

参考 `01-theory/03-审计报告三角模型.md` 第七节:AI 辅助的核心价值,是把报告启动时点(B 点)进一步推向审计开始时点(A 点)——现场访谈、测试结果可即时转化为结构化草稿,而不必等待收尾阶段统一处理。
