# 案例库说明

> 04-case-library / 案例层

## 定位

本目录收录按 FDRRRA 六要素模型(见 `02-methodology/02-审计问题六要素.md`)撰写的完整审计问题案例,所有案例均为**脱敏处理**,仅用于格式与写作方法参考,不对应任何真实机构或个人。

## 版本规划

- **v1.0**:3 个案例(采购、工程、费用领域各一个),验证案例撰写格式
- **v1.1**:扩展至 50 个案例
- **v1.2**:扩展至 100 个案例
- **v2.0**:扩展至 500 个案例,并与 `05-ai/` 的 Prompt 体系联动,支持按关键词检索相似案例

## 案例结构约定

每个案例文件包含两部分:

1. **修改前后对比**——展示同一问题从"底稿式模糊表述"到"报告级精确表述"的进化过程,附审计经理点评,便于新人对照学习(呼应 `02-methodology/03-问题标题写作.md` 中"报告语言与底稿语言的区别")
2. **完整 FDRRRA 结构案例**——按事实/依据/差异/原因/风险/建议六要素完整呈现

## 如何贡献新案例

参考 `CONTRIBUTING.md`,新增案例请:
1. 确保已完全脱敏(不含真实机构、人名、可反推身份的细节)
2. 严格按六要素结构撰写
3. 附一组"修改前后对比"作为教学素材
4. 提交前对照 `02-methodology/07-审计报告十条黄金法则.md` 自查
